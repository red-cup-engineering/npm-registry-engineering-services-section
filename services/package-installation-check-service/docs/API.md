## Verified acceptance cases

Specification basis. Inspect the installed package surface and select an exact registry release.

| Case | Check | Behavior |
| --- | --- | --- |
| ` INSTALLATION-REFUSAL ` | source refusal | A package with missing export targets or references outside its declared closure is refused. |
| ` INSTALLATION-QUICKSTART ` | consumer example | An installed caller selects a package by its exact version when several releases exist. |

Runtime requirement. ` >=22 `
