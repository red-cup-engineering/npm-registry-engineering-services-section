## Verified acceptance cases

Specification basis. A read-only npm snapshot serves GET and HEAD and projects complete package identities onto canonical npm tarball URLs.

| Case | Check | Behavior |
| --- | --- | --- |
| ` REGISTRY-READ-REFUSAL ` | source refusal | The registry accepts read methods and returns Method Not Allowed for POST. |
| ` REGISTRY-READ-QUICKSTART ` | consumer example | An installed caller can project a canonical tarball URL while preserving the original metadata. |

Runtime requirement. ` >=22 `
