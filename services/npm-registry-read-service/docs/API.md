## Verified acceptance cases

Specification basis. A read-only npm snapshot serves GET and HEAD and preserves the artifact path when rewriting public URLs.

| Case | Check | Behavior |
| --- | --- | --- |
| ` REGISTRY-READ-REFUSAL ` | source refusal | The registry accepts read methods and returns Method Not Allowed for POST. |
| ` REGISTRY-READ-QUICKSTART ` | consumer example | An installed caller can change the served tarball origin while preserving its path and the original metadata. |

Runtime requirement. ` >=22 `
