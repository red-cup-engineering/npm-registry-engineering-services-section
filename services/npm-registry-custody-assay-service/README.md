Measures a verdaccio registry's own storage against its published index and each package's attachment catalog, and quarantines the custody defects it finds — packages the index claims that storage never received, tarball addresses that resolve to no attachment, and attachments whose bytes no longer hash to their recorded digest — into an append-only ledger.
